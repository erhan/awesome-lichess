# Awesome Lichess [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> [Lichess](https://lichess.org) is a free, open-source chess platform.

A community-curated directory of tools, projects, guides, articles, and resources for the Lichess ecosystem.

This list is being established. Resource categories and entries will be added as they are curated.

Contributions are welcome! Read the [contribution guidelines](CONTRIBUTING.md) to suggest a resource or improve the list.

This is an independent community project, not affiliated with or officially endorsed by Lichess.
